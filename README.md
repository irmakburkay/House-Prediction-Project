# 🏡 Melbourne Housing Market Prediction and Analysis

A Machine Learning project focused on predicting house prices using the Melbourne housing dataset, featuring exploratory data analysis, advanced feature engineering, and robust regression pipelines.

## 🛠️ Technologies & Methods

- **Python, NumPy & Pandas** – Data manipulation and analysis
- **Scikit-Learn** – Machine learning pipelines, preprocessing, and modeling
- **Seaborn & Matplotlib** – Exploratory Data Analysis (EDA) and visualization
- **Custom Functions & Feature Engineering** – Address parsing, date decomposition, and outlier clipping

## 🎯 Project Highlights

- Built a comprehensive data preprocessing and modeling pipeline using `scikit-learn`'s `Pipeline` and `ColumnTransformer`.
- Performed detailed feature engineering by splitting addresses into street names/types and breaking down sales dates into individual components.
- Implemented robust data cleaning steps, including missing value imputation with `SimpleImputer` and outlier handling via Z-score methods.
- Explored data distribution and correlations using histograms and pairplots.
- Evaluated multiple regression models including Linear Regression, Ridge, Lasso, ElasticNet, Random Forest, and Gradient Boosting.
